我就讀實驗國小，國小階段沒有經歷過段考，也不習慣針對課堂內容做系統性複習。升上國七之後，段考對我完全是新經驗，只能一邊考、一邊調整準備方式。從國七到國八下，我大概經歷了 11 次段考，複習流程也一路改到比較順手。

## 第一種學習方式：國七上第一段、第二段

- 考前準備：用 Google 簡報做心智圖，搭配 Quizlet 整理題庫與背誦內容。
- 前一晚：讀完隔天要考的筆記、複習題庫，準備國文背誦內容。
- 考試當天：再看一次課本重點，臨場補畫還沒準備到的心智圖。

簡報不適合長期整理心智圖，後來改成用 Google Sites。

## 第二種學習方式：國七上第三段

- 考前準備：用 Google Sites 整理各科筆記，Quizlet 整理題庫與背誦。
- 前一晚：讀完隔天要考的筆記、複習題庫，準備國文背誦。
- 考試當天：再看一次課本重點。

Sites 不太適合當筆記本，後來換成 Obsidian。

## 第三種學習方式：國七下第一段、第二段

- 考前準備：用 Obsidian 整理筆記，Quizlet 整理題庫與背誦。
- 前一晚：讀完隔天要考的筆記、複習題庫，準備國文背誦。
- 考試當天：再看一次課本重點。

國七下的歷史變複雜，我開始畫時間軸幫助理解；也試過填空題和手寫的國文背誦卷，想在考前用更主動的方式自測。

## 第四種學習方式：國七下第三段

- 考前準備（學校）：利用主科模考大卷寫完後的空檔，以及少數藝能科自習，準備不好用電腦呈現的內容（例如歷史時間軸）、段考當天可做的填空題，還有國文背誦。
- 考前準備（在家）：Obsidian 整理筆記，Quizlet 整理題庫與背誦。
- 前一晚：讀完隔天要考的筆記、複習題庫，準備國文背誦。
- 考試當天：（國文科：背誦寫完）把填空題寫完、訂正，確認不熟的地方，再看一次課本重點。

實際嘗試後覺得填空題幫助有限，這一步就停掉了。

## 第五種學習方式：國八上第一段、第二段

- 考前準備（學校）：同上，利用主科模考後與藝能自習，準備歷史時間軸、國文背誦。
- 考前準備（在家）：Obsidian 整理筆記，Quizlet 整理背誦。
- 前一晚：讀完隔天要考的筆記、複習題庫，準備國文背誦。
- 考試當天：（國文科：背誦寫完）再看一次課本重點。

這一版我覺得對段考複習最有效。不過 Obsidian 不方便列印，在學校很難紙本複習，後來改成用 Google Docs 整理筆記與背誦內容並印出。

## 第六種學習方式：國八上第三段

- 考前準備（學校）：利用主科模考後與藝能自習，準備歷史時間軸。
- 考前準備（在家）：改為 Google Docs 整理筆記與背誦並印出，Quizlet 整理背誦。
- 前一晚：讀完隔天要考的筆記、複習題庫，準備國文背誦。
- 考試當天：（國文科：背誦寫完）紙本筆記看過一輪，再看一次課本重點。

國八下歷史負擔沒那麼重，筆記也一律用 Google Docs 處理。

## 第七種學習方式：國八下

- 考前準備：Google Docs 整理筆記與背誦（國文、英文、地理、歷史、自然，以及國英背誦）並印出，Quizlet 整理背誦。
- 前一晚：讀完隔天要考的筆記、複習題庫，準備國文背誦。
- 考試當天：（國文科：背誦寫完）紙本筆記看過一輪，再看一次課本重點。

---

整體來說，我認為第五種的流程最適合我；再搭配 Google Calendar、Google Tasks 排時間，比較能在考前把該複習的範圍都跑完。
