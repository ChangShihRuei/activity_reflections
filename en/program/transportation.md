Demo site: [Public Transportation Map](https://public-transportation-map.up.railway.app/)

I've been interested in buses and transportation since I was little, and later started studying the MRT, TRA, HSR, and more. This project aims to turn that experience into a website where users can look up bus, MRT, TRA, and HSR information and plan routes.

## Current Status

An interactive map demo is live—you can toggle bus, TRA, metro, and HSR layers on the map. Route planning and other features are still in development.

## Features

- Interactive map with toggleable bus, TRA, metro, and HSR layers
- Cross-mode route planning (in development)
